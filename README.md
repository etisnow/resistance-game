# Сопротивление (The Resistance) — сетевая социальная дедукция

Игра на 5–10 человек: клиент на **React 16 + PixiJS** (сборка **vite**) и игровой
движок на **socket.io + [Bun](https://bun.sh)**. Обе части поднимаются как
**Docker**-сервисы; Bun — и рантайм, и пакетный менеджер.

Форк карточной игры [«Нечто»](https://github.com/neerone/nechto): от неё достались
комнаты, лобби, реконнект, круглый стол на PixiJS и тестовая обвязка. Правила —
свои, см. **[docs/PRD.md](docs/PRD.md)**; ход работ — **[docs/PLAN.md](docs/PLAN.md)**.

## Правила в двух абзацах

Шпионы знают друг друга, сопротивление не знает никого. Пять раундов: лидер
набирает команду, весь стол голосует за её состав, ушедшая на дело команда тайно
решает исход. Три успешные миссии — победа сопротивления, три сорванные — победа
шпионов. Пять отклонённых составов подряд тоже отдают партию шпионам.

Игра держится на разговоре, а встроенного чата в ней нет: предполагается, что все
сидят в общем голосовом канале.

## Быстрый старт

```bash
./run install      # bun install + Playwright chromium (один раз)
./run server       # движок на :3000, горячая перезагрузка
./run client       # vite dev на :5173, проксирует /socket.io на :3000
```

Дальше открыть **http://localhost:5173**, ввести ник и создать игру. Чтобы
собрать стол, нужно ещё четверо — из соседних вкладок или с других машин.

**Играть одному** (дев-режим): открыть
`http://localhost:5173/?withBots=true&botCount=6` — партия стартует сразу, за стол
садятся боты. `botCount` от 4 до 9, то есть от пяти до десяти игроков вместе с
тобой.

### Весь стек в докере

```bash
./run go           # клиент + сервер + туннель, в фоне, с ожиданием готовности
./run up           # то же в переднем плане, с логами
./run down         # остановить
```

`./run go` требует три значения в `.env` (он в .gitignore):
`CLOUDFLARE_TUNNEL_TOKEN`, `CLIENT_HOST` и `API_HOST`. Туннель Cloudflare
создаётся руками в панели, ingress и DNS живут там; сервисы, на которые его
направляют, — `http://client:5173` и `http://server:3000`.

### Прод

```bash
./run prod up      # сборка образа (vite build + bun bundle) и запуск
```

`vite preview` отдаёт собранный клиент на `:5173` и проксирует `/socket.io` на
бекенд `:3000`. Туннеля здесь нет — прод только на localhost.

## Команды `./run`

| Команда            | Что делает                                                          |
| ------------------ | ------------------------------------------------------------------- |
| `./run go`         | Весь дев-стек в фоне, ждёт готовности                               |
| `./run up`         | То же в переднем плане, с логами                                    |
| `./run down`       | Остановить дев-стек                                                 |
| `./run logs [svc]` | Логи (`client`, `server`, `tunnel`)                                 |
| `./run prod up`    | Собрать и запустить прод-стек                                       |
| `./run install`    | `bun install` + Playwright chromium                                 |
| `./run server`     | Движок локально, горячая перезагрузка                               |
| `./run client`     | vite dev локально                                                   |
| `./run build`      | Клиент (vite → `dist/client`) + сервер (bun → `dist/server`)        |
| `./run start`      | Запустить собранный сервер                                          |
| `./run test`       | Юнит-тесты (`bun test`)                                             |
| `./run e2e`        | Сборка клиента и Playwright                                         |
| `./run typecheck`  | `tsc --noEmit`                                                      |
| `./run clean`      | Убрать `dist/`                                                      |

## Устройство

- `src/server` — движок. `models/Game.ts` — партия и стол, `helpers/round.ts` —
  весь ход раунда (набор команды → голосование → миссия), `server/GameServer.ts` —
  комнаты, лобби и реконнект, `helpers/askDecision.ts` — тайный вопрос игроку с
  таймаутом и автоответом за молчащего.
- `src/client` — React + PixiJS. `controllers/gameController.ts` — состояние
  клиента (mobx), `components/table/` — стол: рассадка, бейджи, трек миссий.
- `src/shared` — общие enum'ы и интерфейсы, включая таблицы правил
  (`constant/resistance.ts`) и контракт сокет-событий.
- `src/_integration` — юнит-тесты движка на мок-сокетах.
- `e2e` — Playwright: лобби, реконнект и полная партия впятером через настоящий
  клиент.
- `analytics/` — аналитический центр, **заморожен** до фазы 4: он построен на
  событиях «Нечто» и сейчас не собирается (см. `docs/PLAN.md`).

## Тесты

```bash
./run typecheck && ./run test && ./run e2e
```

Юнит-тесты гоняют движок на фиксированных сидах — по сценарию на каждое
требование `FR-N` из PRD. E2E поднимают настоящий Chromium: пять браузеров
собираются в лобби и доигрывают партию до победы.
