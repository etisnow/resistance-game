# Сопротивление

Мультиплеерная социальная дедукция на 5–10 игроков: клиент на React 16 + PixiJS
(сборка vite), игровой сервер на socket.io + Bun.

Это форк карточной игры «Нечто» (`github.com/neerone/resistance`), переделываемый в
«Сопротивление». Пока переделка не закончена, большая часть кода в `src/` — ещё
логика «Нечто»: колода, рука, карты, паники. Она подлежит удалению, а не
доработке.

## Порядок работы

1. **Перед работой** прочитай `docs/PLAN.md` — блок «Сейчас» и текущую фазу.
2. **После итерации** отметь сделанное чекбоксами и обнови блок «Сейчас».
   Новые решения и изменившиеся допущения — в «Журнал решений» того же файла.
3. **Что именно изменилось, в план не пиши** — это `git log`. План хранит «что
   дальше» и «почему так».
4. `docs/PRD.md` — источник правды по «что делаем»: требования `FR-N`, модель
   состояния, критерии приёмки. Правится только при смене скоупа или закрытии
   открытого вопроса, и тогда же обновляется его читаемая версия:
   <https://claude.ai/code/artifact/116bd3d9-67e8-43fe-a5dc-d475c3e44e1a>
5. Задачи в плане ссылаются на `FR-N` из PRD. Реализовал требование — проверь,
   что на него есть тест.

## Команды

| Команда | Что делает |
| --- | --- |
| `./run go` | Весь дев-стек в фоне, ждёт готовности |
| `./run server` | Только бэкенд (bun), горячая перезагрузка |
| `./run client` | Только vite dev server на `:5173` |
| `./run test` | Юнит-тесты движка (`bun test`) |
| `./run typecheck` | `tsc --noEmit` |
| `./run e2e` | Сборка клиента + Playwright |

Дев-режим с ботами — `?withBots=true&botCount=N` в адресе клиента. Там же
`&seed=777` закрепляет раздачу, а `&activeRole=merlin|assassin|percival|morgana`
выдаёт тебе эту роль и заодно заводит партию с нужным дополнением.

## Устройство

- `src/server` — игровой сервер. `models/Game.ts` — партия, `server/GameServer.ts`
  — комнаты, лобби и реконнект, `helpers/askDecision.ts` — тайный вопрос игроку с
  таймаутом и автоответом.
- `src/client` — React + PixiJS. `controllers/gameController.ts` — состояние
  клиента (mobx), `components/table/` — стол.
- `src/shared` — общие enum'ы и интерфейсы, включая контракт сокет-событий.
- `src/_integration` — юнит-тесты движка на мок-сокетах.
- `analytics/` — отдельный пакет: сбор статистики по законченным партиям.
  **Заморожен до фазы 4**: построен на событиях «Нечто» и не собирается,
  `./run analytics` об этом говорит.

## Соглашения

- Комментарии и игровые тексты — по-русски, как в существующем коде.
- Комментарий объясняет **почему** так сделано, а не что делает строка. Образец
  тона — комментарии в `src/server/models/Game.ts`.
- Партия воспроизводима по сиду: вся случайность идёт через `game.rng`, а не
  `Math.random`. В тестах сид фиксируется явно.
